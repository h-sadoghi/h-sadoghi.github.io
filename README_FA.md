# اصلاح راست‌به‌چپ فصل‌های داده‌کاوی در سایت

این بسته برای اصلاح نمایش فارسی در کتاب Jupyter Book درس **Data Mining** آماده شده است.

## کاری که این بسته انجام می‌دهد

- یک فایل CSS اختصاصی برای کتاب داده‌کاوی اضافه می‌کند.
- فایل `_config.yml` کتاب را طوری به‌روزرسانی می‌کند که این CSS فقط روی کتاب Data Mining اعمال شود.
- برای فصل‌های فعلی (فصل ۱ و ۲) و فصل‌های بعدی، پاراگراف‌ها، فهرست‌ها، جدول‌ها و کپشن‌ها را راست‌چین و راست‌به‌چپ می‌کند.
- بلوک‌های کد، خروجی نوت‌بوک و فرمول‌های ریاضی را چپ‌به‌راست نگه می‌دارد تا خراب نشوند.

## مسیر کپی

محتویات این ZIP را در ریشه‌ی مخزن سایت کپی کنید:

`J:\SadoghiSite2\h-sadoghi.github.io`

طوری که فایل‌ها به این مسیرها برسند:

- `courses/data-mining/book/_config.yml`
- `courses/data-mining/book/_static/data-mining-rtl.css`

## پس از کپی

1. در دانشگاه، تغییرات را در مخزن سایت Commit کنید.
2. Build یا روال انتشار سایت را اجرا کنید.
3. سپس صفحه‌های زیر را با `Ctrl+F5` باز کنید:
   - `/teaching/data-mining/book/`
   - `/teaching/data-mining/book/course-notes/chapter-01.html`
   - `/teaching/data-mining/book/course-notes/chapter-02.html`

## نکته

نیازی به تغییر متن فصل‌ها نیست؛ این اصلاح در سطح کتاب اعمال می‌شود و برای فصل‌های موجود و آینده کافی است.
