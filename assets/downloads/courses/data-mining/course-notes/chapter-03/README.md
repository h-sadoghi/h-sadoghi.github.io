# Chapter 3 downloads / فایل‌های فصل سوم

برای راهنمای فارسی، فایل `README_FA.md` را مطالعه کنید.

```cmd
RUN_CHAPTER03_EXAMPLES.cmd
```

برای بازتولید محاسبات در خط فرمان:

```bash
python chapter03_examples.py
python -m unittest test_chapter03_examples.py -v
```

برای PDF از فایل آماده استفاده کنید؛ اگر XeLaTeX نصب دارید، `BUILD_PDF_ONE_CLICK.cmd` را اجرا کنید. شکل‌ها در پوشهٔ مجاور `../images` هستند.
