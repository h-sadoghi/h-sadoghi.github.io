# راهنمای اجرای کدهای فصل سوم

تمام داده‌های این پوشه ساختگی و برای آموزش هستند. برنامهٔ اصلی فقط به **Python 3.9+** و کتابخانهٔ استاندارد نیاز دارد.

## اجرای سریع در Windows

روی `RUN_CHAPTER03_EXAMPLES.cmd` دوبار کلیک کنید. در پایان، اگر همهٔ ۸ آزمون موفق شوند، گزارش `chapter03_results.json` در همین پوشه ایجاد می‌شود.

## اجرای خط فرمان

```bat
python chapter03_examples.py
python -m unittest test_chapter03_examples.py -v
```

## Notebook

`chapter03_examples.ipynb` را در Jupyter باز کنید. در صورتی که فایل Python کنار Notebook باشد، نتایج بازتولید می‌شوند. با Notebook می‌توان مقادیرِ ورودی را تغییر داد و نتیجه را بررسی کرد.

## بازتولید شکل‌ها

شکل‌ها آماده‌اند و برای اجرای مثال‌ها نیازی به بازسازی آن‌ها نیست. برای ساخت دوبارهٔ ۱۸ شکل، بسته‌های اختیاری را از `requirements_optional.txt` نصب کنید و `generate_figures_optional.py` را اجرا کنید. این اسکریپت داخل سورس کاملِ ZIP همراه فصل قرار گرفته است و هنگام استخراج بستهٔ سورس، مسیر `images/` را پیدا می‌کند. اجرای آن در پوشهٔ فعلی `downloads/` بدون ساختار کامل سورس توصیه نمی‌شود.

## دامنهٔ اعتبار مثال‌ها

- قرارداد Jaccard برای دو مجموعهٔ خالی: شباهت ۱.
- Cosine برای بردار صفر نامعین است و خطا می‌دهد.
- KL از لگاریتم پایهٔ ۲ استفاده می‌کند؛ واحد بیت است.
- فاصلهٔ Gower در نبود هر ویژگی قابل‌مقایسه `NaN` برمی‌گرداند.
- ماتریس کوواریانس در مثال Mahalanobis قطری و با واریانس‌های مثبت است.
- برای دادهٔ واقعی، متریک باید با واحد مشاهده، مقیاس، اعتبارسنجی و مفروضات مسئله انتخاب شود.
