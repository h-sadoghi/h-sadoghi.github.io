# فایل‌های اجرایی فصل ۸

- `chapter08_examples.py`: آنتروپی، کدهای هافمن و اجرای آزمایش WebP؛ `python chapter08_examples.py`
- `chapter08_huffman.py`: ساخت فایل آموزشی `toy_huffman.hf8` و بازیابی دقیق آن؛ `python chapter08_huffman.py`
- `chapter08_webp.py`: مقایسه PNG و WebP در کیفیت‌های گوناگون؛ `python chapter08_webp.py`
- `chapter08_examples.ipynb`: نمونه‌های مستقل برای Jupyter

برای هافمن فقط Python استاندارد کافی است. برای WebP به `Pillow` با پشتیبانی WebP نیاز دارید. هیچ بسته‌ای به‌طور خودکار نصب نمی‌شود.

`HF08` فقط **قالب آموزشی مخصوص این جزوه** است، نه قالب استاندارد برای تبادل تصویر. هزینه کدبوک/سرآیند در فایل واقعی محاسبه می‌شود. تصاویر آزمایش، ساختگی و اصیل هستند.
