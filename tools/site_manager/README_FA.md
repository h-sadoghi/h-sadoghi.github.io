# راهنمای سادهٔ مدیریت محتوای محلی سایت

## اجرا

1. روی `RUN_SITE_MANAGER.cmd` دوبار کلیک کنید.
2. در اولین اجرا، محیط Python و بسته‌های لازم ساخته می‌شوند؛ اینترنت فقط برای همین نصب اولیه لازم است.
3. مرورگر در `http://127.0.0.1:8765` باز می‌شود. ابزار فقط روی همین رایانه در دسترس است.

## افزودن محتوا

1. «افزودن محتوای جدید» را انتخاب کنید.
2. نوع و مقصد را **خودتان** انتخاب کنید؛ ابزار بخش دانشگاهی را حدس نمی‌زند.
3. عنوان و اطلاعات دلخواه را وارد کنید. برای جلوگیری از انتشار پیش از موعد، وضعیت اولیه «پیش‌نویس» است.
4. فایل Markdown یا متن و تصویر/PDFهای مربوط را انتخاب کنید.
5. «پیش‌نمایش و نمایش تغییر دقیق» را بزنید. مسیر، URL، front matter، diff، تعارض و فایل‌های رسانه‌ای را ببینید.
6. تنها اگر نتیجه درست است «تأیید و ذخیره در مخزن محلی» را بزنید.

برای ویرایش، «ویرایش فایل موجود» و مسیر فایل را انتخاب کنید. permalink موجود در ویرایش عادی حفظ می‌شود. هر ذخیره یک پشتیبان محلی در `.site-manager-backups/` می‌سازد. ابزار Commit یا Push نمی‌کند.

## پیش‌نمایش

«پیش‌نمایش سریع Markdown» بدون Ruby کار می‌کند. دکمهٔ «اجرای پیش‌نمایش Jekyll» سایت واقعی را روی `http://127.0.0.1:4000` می‌سازد و پس از آماده‌شدن در مرورگر باز می‌کند. پیش‌نویس‌های دارای `published: false` نیز فقط در این پیش‌نمایش محلی دیده می‌شوند و وضعیت انتشار فایل تغییر نمی‌کند.

اولین ساخت ممکن است چند دقیقه طول بکشد. وضعیت و انتهای لاگ در همان صفحه نمایش داده می‌شود. اگر سرور از قبل به‌وسیلهٔ Site Manager اجرا شده باشد دوباره استفاده می‌شود؛ اگر برنامهٔ دیگری پورت 4000 را گرفته باشد پیام خطای روشن می‌بینید. برای آزادکردن پورت از دکمهٔ «توقف Jekyll» استفاده کنید.

## GitHub Desktop پس از ذخیره

1. مخزن `J:\SadoghiSite2\h-sadoghi.github.io` و شاخهٔ feature درست را در GitHub Desktop انتخاب کنید.
2. همهٔ Changes و diffها را بازبینی و سپس Commit محلی کنید.
3. شاخهٔ feature را به Fork `hadisadoghiyazdi1971/h-sadoghi.github.io` Push کنید.
4. Pull Request به `h-sadoghi/h-sadoghi.github.io:master` بسازید.
5. پس از سبزشدن آزمون‌ها و تأیید مالک، PR را Merge کنید.

**Push به Fork به‌تنهایی سایت تولیدی را به‌روزرسانی نمی‌کند.** Push مستقیم به تولید نیازمند مجوز و تنظیم حساب جداگانه است.

## خط فرمان و API کوچک

اجرا: `python -m tools.site_manager --repo J:\SadoghiSite2\h-sadoghi.github.io`

کلاس `tools.site_manager.SiteManager` متدهای `preview_add`, `add`, `preview_edit`, `edit` و `validate` را برای کارهای دسته‌ای ارائه می‌کند. عملیات نوشتن به `confirm=True` و یک Preview بدون خطا نیاز دارد.
