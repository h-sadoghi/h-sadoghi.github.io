روند امن GitHub Desktop

  1. پس از ذخیره در ابزار، GitHub Desktop را باز کنید و مطمئن شوید مخزن J:\SadoghiSite2\h-sadoghi.github.io و شاخهٔ feature درست انتخاب شده است.
  2. فهرست Changes و diff هر فایل را بازبینی کنید؛ سپس یک Commit محلی با پیام روشن بسازید.
  3. شاخهٔ feature را فقط به Fork حساب hadisadoghiyazdi1971 Push کنید.
  4. از Fork یک Pull Request به h-sadoghi/h-sadoghi.github.io:master بسازید.
  5. پس از سبزشدن Build، Prettier و link checks و تأیید مالک، PR را Merge کنید.

Push به Fork به‌تنهایی سایت تولیدی را تغییر نمی‌دهد. Push مستقیم به مخزن تولیدی نیازمند تنظیم جداگانهٔ حساب و مجوز است.
